Real-Time Fraud Detection Pipeline

Kafka · Spark Structured Streaming · PostgreSQL · XGBoost · MLflow · FastAPI · Prometheus · Grafana · Streamlit
View Repo →

An end-to-end, production-shaped MLOps system: transactions stream through Kafka, Spark computes windowed features (rolling transaction count, average amount) into a Postgres feature store, an XGBoost model trained on the real Kaggle credit-card fraud dataset is registered in MLflow, and a FastAPI service serves live predictions — all instrumented with Prometheus/Grafana and a Streamlit dashboard, shipped with GitHub Actions CI/CD.

Producer→ Kafka→ Spark (windowed)→ Postgres→ MLflow registry→ FastAPI /predict→ Grafana

Run the real pipeline, then embed it here

Set liveDemoUrl in the CONFIG block to a public URL and this panel will load your actual Streamlit dashboard.

  • 1. In VS Code terminal, from the project folder: docker compose up -d
  • 2. Start the dashboard: streamlit run dashboard.py
  • 3. Expose it publicly: ngrok http 8501 (or npx localtunnel --port 8501)
  • 4. Copy the generated https URL into SITE_CONFIG.liveDemoUrl in this file's CONFIG block near the top
  • 5. Reload this page — the panel above will show your real, running dashboard
